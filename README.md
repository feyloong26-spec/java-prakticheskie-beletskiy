## Как открыть и показать преподавателю

1. Откройте папку проекта (где находятся `.run`, `pom.xml`, `src`) через **File → Open** в IntelliJ IDEA. Для проекта с GitHub используйте **Get from VCS** и вставьте ссылку именно на отдельный репозиторий практических работ.
2. При запросе **Trust Project** подтвердите. Выберите установленный JDK 17 или новее и дождитесь импорта Maven.
3. **ВВЕРХУ СПРАВА** нажмите на список рядом с зелёным треугольником. Выберите запуск по номеру из списка ниже, нажмите ▶ **Run**.
4. Внизу откроется консоль **только выбранного задания**, без вывода остальных. Переключаться между запусками можно через список сверху и вкладки `Run`.
5. Чтобы показать код, раскройте слева `src → main → java → ru.beletskiy → tasks` и папку нужного задания; её `Main.java` запускает демонстрацию. Классы реализаций находятся в пакетах `part1`, `part2`, `part3`, `part4` и `additional`.
6. Если запуск не появился в списке, дождитесь загрузки Maven, затем используйте зелёный треугольник возле `main()` в соответствующем `Main.java`.

**Важно:** это не восемь объединённых меню, а 28 отдельных заданий плюс независимая проверка. Все файлы `Main.java` содержат свой `main()`. При запуске задания 4 из части 1 будет показано только задание 4.

## Что важно перед сдачей

- **ПР1 часть 1, пункты 1 и 2** — организационные: создать проект IntelliJ и **собственный Git-репозиторий**. Порядок размещения и проверки через IDE описан в [инструкции Git и IntelliJ IDEA](docs/GIT_IDEA.md). Архив сам по себе не подтверждает публикацию на GitHub.
- **ПР1 часть 1, пункт 8** — загрузить результаты в репозиторий и показать преподавателю. Это не исполняемое Java-задание.
- **Часть 3, Shape:** ошибки компиляции из методички (`new Shape()`, `s1.getRadius()`, `r2.getSide()`) оставлены комментариями в `part3/shapes/TestShape.java`; намеренно ломающий компиляцию код не включён.
- **ПР4, задание 4 «Компьютер»** — добавлены классы `Computer`, `Processor`, `Memory`, `Monitor`, `Brand` и `TestComputer`.
- **Дополнительные задания** включают два упражнения с ошибками и два самостоятельных задания (`Rectangle`, `Stock`). UML-схемы для основных классов находятся в `docs/` и открываются в браузере.
- **Примеры** используют заранее заданные числа, если методичка не требует ввода с клавиатуры. Интерактивные задачи: `01.04`, `01.07`, `04.03`. В задаче с аргументами `01.05` они уже установлены в конфигурации и меняются через **Run → Edit Configurations → Program arguments**.
- **ПР4.1, транспорт** использует демонстрационные тарифы/скорости, так как в условиях нет конкретных чисел.
- **Автоматическая проверка** подтверждает ряд вычислений, но не является доказательством полного соответствия всем требованиям преподавателя.

## Структура проекта

```text
Beletskiy_Java_Po_Kazhdomu_Zadaniyu/
├── .run/                        # отдельные запуски IntelliJ IDEA
├── docs/                        # готовые UML-диаграммы в SVG
├── src/main/java/ru/beletskiy/
│   ├── tasks/                   # Main.java для каждого задания
│   ├── part1/                   # основа для первой части
│   ├── part2/                   # Author, Ball
│   ├── part3/                   # Shape, Movable
│   ├── part4/                   # enum, ателье, магазин, компьютер, ООП
│   ├── additional/              # дополнительные задания
│   └── Verification.java        # автоматические проверки
└── pom.xml                      # проект Maven без внешних библиотек
```

Рекомендуется демонстрировать каждый пункт так: **название запуска → код в `Main` и связанных классах → консоль с результатом**.
